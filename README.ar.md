## الاستخدامات المناسبة والمشكلات التي يحلها

لمن يريد رسمًا مفاهيميًا يُظهر استكشاف التصميم دون تتبع الصورة كاملة. يحفظ Panel 120 الهوية والذاكرة المكانية ويختزل الأشكال والخطوط والعلاقات الأساسية إلى خطوط منظور حرة. تتعاون المساحات اللونية القليلة والخطوط المرجعية الهندسية والفراغ الواسع في تشكيل العمل.

### مناسب لهذه الحالات

- تحويل صور العمارة والأماكن والسفر والأشياء إلى رسم مفاهيمي بطابع تحريري.
- إنقاذ تكوين ضعيف أو خلفية مزدحمة أو موضوع صغير بالحذف وإعادة الترتيب وتغيير المقياس.
- حفظ قابلية التعرف والعلاقات المكانية دون تلوين شامل أو تصيير واقعي.
- توحيد الأسلوب في المقارنات والتصميم المنفرد والخلفيات ومعالجة المجلدات.

### ما الذي يحله

- يحذف الخلفية والأشياء الثانوية ليحفظ الأشكال الجوهرية والذاكرة البصرية.
- يستخدم خطوط منظور وإنشاء مقتصدة ومتكررة قليلًا لإظهار استكشاف التصميم.
- يجعل الفراغ جزءًا من التكوين بدل ملء الصفحة بالزينة.
- يقصر المقارنة على منطقتين متساويتين، وينشئ كل أصل بصورة مستقلة دون تحويل أسلوبي ثانٍ.

## النص الأصلي · خمس لغات

[简体中文](references/original-prompt/zh-CN.md) · [English](references/original-prompt/en.md) · [日本語](references/original-prompt/ja.md) · [한국어](references/original-prompt/ko.md) · [العربية](references/original-prompt/ar.md)

يحفظ الملف الصيني أصل المستخدم حرفيًا وهو المرجع الإبداعي والجمالي الوحيد عند التشغيل. الإصدارات الأخرى ترجمات كاملة وأمينة للقراءة.

اسكتش منظور معماري مفاهيمي · خطوط يدوية · مراجع هندسية · ألوان وظلال قليلة · 2–4 ألوان من الأصل · فراغ واسع · ملاحظات تحريرية ضئيلة

## كيف تتحول الصورة إلى عمل

فهم الموضوع والعلاقات المكانية → اختزال الأشكال الجوهرية → حذف الخلفية المعقدة → إعادة ضبط المقياس والاقتصاص → البناء بخطوط منظور ومراجع هندسية وألوان قليلة → الإنهاء بالفراغ والملاحظات القصيرة

## ملامح العمل النهائي

- تبقى الصورة أعلى أو يسارًا مع تعديل لوني طفيف دون تغيير الهوية والوضعية.
- التصميم رسم معماري مفاهيمي وليس نسخًا للمشهد كاملًا أو تصييرًا واقعيًا أو 3D.
- الموضوع صغير ومختزل، ويمكن إزاحته أو وضعه قرب الحافة أو اقتصاصه جزئيًا؛ ويشارك الفراغ في التكوين.
- تُستخلص 2–4 ألوان من الأصل لتشكيل مجموعة نظيفة ومقتصدة، وتُطبق بخفة في المواضع الرئيسية فقط.
- تُظهر الظلال الهندسية الكتلة والعمق وتحفظ بعض الخطوط المساعدة إحساس الاستكشاف.
- يستقر نص قليل بهدوء في الفراغ دون قالب خط ثابت؛ تستخدم النماذج الإنجليزية.

يعيد وضع التسليم المختار توزيع التخطيط فقط دون تغيير جماليات الأصل: ينقل `left-right` الصورة العلوية إلى اليسار والتصميم السفلي إلى اليمين. تتقدم النسبة المختارة على نسبة الأصل الافتراضية `3:4`.

## أنماط الإخراج الأربعة

- `top-bottom`: منطقتان أفقيتان كاملتا العرض فقط؛ الواقع في الأعلى والتصميم في الأسفل، 50% لكل منهما.
- `left-right`: منطقتان عموديتان كاملتا الارتفاع فقط؛ الواقع يساراً والتصميم يميناً، 50% لكل منهما، ولا يتحول إلى تخطيط علوي/سفلي.
- `design-only`: تعرض اللوحة الكاملة ترجمة Panel 120 التصميمية فقط، وتبقى الصورة مرجعاً غير ظاهر.
- `wallpaper-pack`: ينشئ عملاً كاملاً للهاتف وiPad وسطح المكتب والساعة، إما كعائلة `linked` أو أربعة أعمال `independent`.

يمكن جمع الأنماط والأحجام. تشمل النسب `1:1` و`3:4` و`4:3` و`4:5` و`5:4` و`2:3` و`3:2` و`9:16` و`16:9` و`21:9` و`5:7` و`7:5` والبكسلات الدقيقة. يمكن أن يكون النص مولداً أو حرفياً من المستخدم أو غائباً. عند إدخال مجلد، تُعالج كل صورة بمعزل عن الأخرى مع إعدادات تسليم مشتركة، وتوضع ملفات PNG النهائية مباشرة في مجلد مهمة جديد واحد.

## البدء

```bash
git clone https://github.com/nevertoday/xxd-panel-120.git
npx skills add https://github.com/nevertoday/xxd-panel-120 --skill xxd-panel-120
```

بعد التثبيت أعد تشغيل جلسة Agent ثم استدعِ `$xxd-panel-120`. ويمكن إضافة `--global --agent codex --yes` للتثبيت على مستوى المستخدم.

```text
/xxd-panel-120 photo.jpg --mode top-bottom --size 3:4 --text prompt --locale ar-SA
/xxd-panel-120 photo.jpg --mode left-right --size 16:9 --text prompt --locale en-US
/xxd-panel-120 photo.jpg --mode design-only --size 9:16 --text none
```
